# ⚡ Ejercicios de JavaScript — 2º DAW (DWCC)

¡Bienvenido/a a mi repositorio de prácticas y ejercicios de **Desarrollo Web en Entorno Cliente (DWCC)**! Este espacio está diseñado para recopilar, organizar y hacer un seguimiento de todo mi aprendizaje con JavaScript y las tecnologías del lado del cliente durante el segundo curso del ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

---

## 🎯 Objetivo

El propósito principal de este repositorio es:
- 📌 **Seguimiento del progreso:** Documentar mi evolución y dominio de JavaScript moderno (ES6+), la manipulación del DOM y la asincronía.
- 💾 **Respaldo:** Mantener un registro seguro y centralizado de todas las actividades y prácticas resueltas.
- 🛠️ **Consulta:** Servir como base de código y referencia rápida para futuros proyectos web.

---

## 🛠️ Tecnologías y Herramientas

- **Lenguaje:** JavaScript (ES6+), HTML5, CSS3
- **Entorno de Ejecución / Pruebas:** Navegador Web (Chrome/Firefox), Node.js
- **Editor de Código:** Visual Studio Code (VS Code)
- **Gestor de Control de Versiones:** Git & GitHub
